# Grace Ledger

SUPER PROMPT — IGREJA FÁCIL (LOVABLE)

Crie um aplicativo SaaS completo chamado “Igreja Fácil”.

O sistema será um app moderno de gestão ministerial focado em simplicidade, clareza financeira e experiência intuitiva para igrejas.

IMPORTANTE:
Esse projeto NÃO deve parecer um ERP complexo.
Ele deve parecer:

leve;

moderno;

extremamente fácil de usar.

A inspiração visual deve misturar:

minimalismo moderno;

neumorphism suave;

O foco visual principal deve ser:

hierarquia clara.
